About this map

Map data © OpenStreetMap contributors. Bars/pubs/nightclubs and named attractions use real OpenStreetMap coordinates. Beach-activity pins (jet ski, banana boat, parasailing, etc.) are approximate placements along the real beachfront — those operators move and change season to season, so confirm details (opening hours, current ownership, exact spot) before relying on this for a night out. Edit the bars / activities arrays in this file to correct or extend the list.
